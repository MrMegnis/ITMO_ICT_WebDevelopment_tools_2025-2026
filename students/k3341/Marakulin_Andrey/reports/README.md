# README для проекта отчетов

## Описание

Этот проект содержит отчеты по лабораторным работам, подготовленные с помощью MkDocs.

## Структура проекта

```
reports/
├── mkdocs.yml           # Конфигурация MkDocs
├── docs/                # Исходные файлы документации
│   ├── index.md        # Главная страница
│   ├── lab1/           # Отчет по ЛР1
│   ├── lab2/           # Отчет по ЛР2
│   └── lab3/           # Отчет по ЛР3
├── README.md           # Этот файл
└── site/               # Сгенерированный сайт (создается при build)

```

## Установка

### Требования
- Python 3.7+
- pip

### Установка зависимостей

```bash
# Активируйте виртуальное окружение
.\.venv\Scripts\Activate.ps1   # Windows PowerShell
source .venv/bin/activate       # Linux/Mac

# Установите зависимости
pip install mkdocs mkdocs-material
```

## Использование

### Локальный просмотр (Live Server)

```bash
mkdocs serve
```

После этого откройте в браузере: `http://127.0.0.1:8000`

### Сборка статического сайта

```bash
mkdocs build
```

Статический сайт будет создан в папке `site/`

### Публикация на GitHub Pages

```bash
mkdocs gh-deploy
```

## Редактирование отчетов

1. Откройте нужный файл из папки `docs/`
2. Измените содержимое (файлы в формате Markdown)
3. Сохраните файл
4. Обновите страницу в браузере (если используется `mkdocs serve`)

## Синтаксис Markdown

### Заголовки
```markdown
# Заголовок 1
## Заголовок 2
### Заголовок 3
```

### Текст
```markdown
**Жирный** текст
*Курсивный* текст
~~Зачеркнутый~~ текст
```

### Списки
```markdown
- Пункт 1
- Пункт 2
  - Подпункт
```

### Таблицы
```markdown
| Колонка 1 | Колонка 2 |
|-----------|-----------|
| Данные 1  | Данные 2  |
```

### Код
```markdown
`inline code`

\`\`\`python
def hello():
    print("Hello")
\`\`\`
```

### Ссылки
```markdown
[Текст ссылки](https://example.com)
[Локальная ссылка](../path/to/file.md)
```

### Адмонишены (заметки)
```markdown
!!! note "Заголовок"
    Содержание заметки

!!! warning "Внимание"
    Важная информация

!!! success "Успех"
    Положительный результат
```
