# Полезные ссылки и материалы
> **Если вы хотите найти дополнительный материал или подкрепить полученные знания в другом изложении можете воспользоваться следующими источниками:**

1. [Документации FastAPI - туториалы](https://fastapi.tiangolo.com/ru/tutorial/) - FastAPI 101. Пошаговое объяснение того как работать с фреймворком
2. [Документации Pydantic](https://docs.pydantic.dev/latest/) - Объясняет как базовые концепции сериализации и валидации на примере библиотеки и дает рецепты как ими пользоваться
3.  FastAPI: Modern Python Web Development - Билл Любанович - Step-by-Step объяснение как создать свое приложение, какие 
паттерны, библиотеки и технологии применять прии разработке. Так же дает обзор других подходов и решений в рамках разработки веб-приложений и использования фреймворка
4. [Артём Шумейко, youtube-канал](https://www.youtube.com/@artemshumeiko/playlists)  - Видеоаналог предыдущиих источников. В простом изложении и на реальных 
примерах показывает как создавать свое приложение и интегрировать в него паттерны и технологии
5. Проектирование архитектуры API. Как правильно проектировать, развивать и эксплуатировать API - 
Гоф Джеймс, Брайант Дэниэл, Оберн Мэтью. - Более фундаментальная книга, предоставляющая архитектурные решения для разработки приложений предоставляющих внешний API
6. RESTful Web API паттерны и практики - Амундсен Майк. - Книга, описывающая паттерн проектировки API-сервисов с использованием гиипермедиа. Содержат 
структурирование описание подхода разработки открытого и архитектурно надежного API с точки зрения понятия гипермедиа.
